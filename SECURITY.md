# Security policy

PortalSwitch handles keyboard, mouse, clipboard and file data between your computers, so
security reports are taken seriously.

## Reporting a vulnerability
Please do **not** open a public issue. Use GitHub's private vulnerability reporting on this
repository ("Security" tab → "Report a vulnerability"). Include affected version, platform,
and steps to reproduce.

You can expect an acknowledgement within a few days. Fixes are released first, then
disclosed with credit to the reporter unless you prefer to stay anonymous.

## Supported versions
Until 1.0, only the latest release receives security fixes.

## Scope
Pairing and trust, TLS channel, message parsing, clipboard and file handling, local IPC and
installer/update integrity.
