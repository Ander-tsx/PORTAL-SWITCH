Free & open source · Apache-2.0 · Early development

One keyboard and mouse.
Every computer.

Move your pointer off the edge of one screen and it continues on the next machine. Keyboard, clipboard and files follow. macOS and Windows, up to five computers, no cables.

View on GitHub ☕ Buy me a coffee

Low latency

Dedicated input channel that file and clipboard traffic can never delay.

Secure by default

Always encrypted with TLS 1.3, mutual authentication, pairing with a short code.

Right keys, any layout

Character, physical and shortcut modes, with a visual editor for modifier mappings.

Clipboard & files

Copy on one machine, paste on another. Drag files across the edge.

Easy setup

Same app everywhere, no server and client roles. Arrange screens visually and you're done.

Open and private

No ads, no tracking, no accounts. Read the code, build it yourself.

Keep it free

PortalSwitch has no paid tier. Donations are optional and pay for code-signing certificates, test hardware and maintainer time.
