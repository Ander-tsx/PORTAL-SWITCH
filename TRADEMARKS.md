# Trademark and branding policy

PortalSwitch is open source under the [Apache License 2.0](LICENSE). That license covers the
source code. It does **not** grant any right to use the project's names, logos or other
branding (Apache-2.0 §6).

**Covered marks:** "PortalSwitch", "Portal Switch", the PortalSwitch logo, icon and
wordmark, and the official download, website and donation channels.

## You may, without asking
- Fork, modify, build and redistribute the code under the terms of the license.
- State truthfully that your software is based on, compatible with, or a fork of
  PortalSwitch ("Based on PortalSwitch", "Compatible with PortalSwitch").
- Refer to PortalSwitch by name in articles, reviews, tutorials and documentation.
- Package unmodified official releases (for example in Homebrew, winget or Scoop) under the
  official name.

## You may not
- Name a modified or competing product "PortalSwitch", "Portal Switch" or anything
  confusingly similar, or use the logo or icon for it.
- Present a build as official if it is not produced and signed by the project.
- Use the project's name, logo or visual identity in a way that suggests endorsement or
  affiliation that does not exist.
- Redistribute builds that bundle adware, telemetry, crypto-miners or other undisclosed
  additions under the PortalSwitch name.
- Collect donations or payments while presenting yourself as the PortalSwitch project.

## Forks
A fork must pick its own name and visual identity, keep the copyright and license notices
(LICENSE, NOTICE), and mark changed files as required by Apache-2.0 §4.

## Official channels
Only releases published from this repository's GitHub page and the project website are
official. Anything else is unofficial, even if it carries the same name.

Questions or permission requests: open an issue titled "Trademark".
